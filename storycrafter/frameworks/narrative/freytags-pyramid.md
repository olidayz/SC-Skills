# Freytag's Pyramid

## What It Is
Gustav Freytag's dramatic structure — a visual model showing how tension rises and falls. Originally for tragedy analysis, now useful for understanding pacing in any story. Think of it as a tension map.

## The Shape

```
        CLIMAX
        /    \
       /      \
RISING/        \FALLING
ACTION          ACTION
     /            \
    /              \
EXPOSITION    DENOUEMENT
```

## The 5 Parts

1. **Exposition** — Characters, world, status quo. The ground level.
2. **Rising Action** — Complications, obstacles, escalating stakes. Tension climbs.
3. **Climax** — The peak. Maximum tension. The turning point where the outcome is decided.
4. **Falling Action** — Consequences of the climax play out. Tension decreases but stakes remain.
5. **Denouement** — Resolution. New equilibrium. Loose ends addressed.

## When to Use It
- **Best for:** Understanding pacing. Use as an overlay on any other framework to check your tension arc.
- **Tone fit:** Originally tragedy, but the shape applies universally
- **Format fit:** Features (pacing check), shorts (compressed pyramid), ads (micro-pyramid)
- **Real use:** Not usually a primary framework — it's a diagnostic tool. "Is my tension arc working?"

## For Short-Form (30s)
- Exposition: 2-3s
- Rising: 10-15s
- Climax: 5s
- Falling: 3-5s
- Denouement: 2-3s

## Example
**The Shining:** Exposition: Jack takes the caretaker job, family arrives at the Overlook. Rising: Isolation, the twins, "All work and no play," Jack deteriorating. Climax: Jack breaks through the door ("Here's Johnny!"). Falling: Chase through the maze. Denouement: Jack freezes, Wendy and Danny escape.

## Common Pitfalls
- Treating it as a writing framework instead of an analysis tool
- Climax too early (pyramid becomes lopsided — falling action drags)
- Climax too late (no room for falling action — ending feels rushed)
